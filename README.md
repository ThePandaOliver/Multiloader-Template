# Minecraft Modding Template

This template helps you create Minecraft mods that work with Fabric, Forge, and NeoForge. It makes use of:
- **[Architectury Loom](https://docs.architectury.dev/loom/introduction)** – Compiler for Fabric, Forge, and NeoForge.
- **[Stonecutter](https://stonecutter.kikugie.dev/)** – C-like Preprocessor for Minecraft mod development.
- **[Forgix](https://github.com/PacifistMC/Forgix)** – Combines different loaders and versions into a single jar.
